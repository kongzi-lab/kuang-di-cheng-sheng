# 匡地成圣论｜Sainthood at Kuang

孔子约56岁时在匡地被天命拣选为圣人的历史与哲学研究。

## 📄 论文

本仓库收录论文 **《子畏于匡：孔子"匡地成圣"论——成圣的时空坐标》** 及相关研究。

**核心发现**：孔子在匡地（今河南境内）被围困的绝境中，通过"文不在兹乎"的自我献祭，被上天拣选为圣人。这不是渐修的结果，也不是死后的建构，而是一个真实发生在约公元前496年的精神质变。
